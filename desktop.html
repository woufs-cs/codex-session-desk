三个对象，三个作用

本机项目按 Codex 数据目录与 Project ID 区分，目录相同也可以是两个项目。“项目属性”编辑同步名称；原生项目名称、对话标题和归属通过明确按钮修改并验证。ID 与消息正文只读。

项目 Project

名称、身份、关联目录与成员清单。

对话 Thread

独立 ID、标题、工作目录和消息历史。

本机关联

云端项目对应本机哪个目录、哪个 Codex 项目。

工作目录表示在哪里运行；项目归属表示显示在哪个 Codex 项目下。两台机器的路径和原生项目 ID 可以不同。

每天切换机器怎么做

离开前：结束当前操作 → 本机项目勾选对话 → 保存并发布快照。使用本地同步文件夹时，等待同步工具上传完成。

到另一台：等待同步文件夹下载完成 → 云端项目检查最新快照及来源设备 → 预览接收 → 确认目录与标题 → 关闭 Codex → 接收并验证 → 重新打开 Codex。新增对话需手动勾选；不要让两台机器同时继续同一条对话。

同步如何处理差异

相同内容跳过；远端有追加则更新并备份；本地更完整则保留；双方分叉时可保留独立对话或跳过。归属冲突会停止提示，不静默移动。

冲突处理在接收确认窗口选择，对本次内容分叉统一生效。“保留分叉”保留本机对话、把远端版本恢复为另一个 ID；“跳过冲突”保留本机版本并继续处理其他非冲突对话。不自动合并两边消息，不提供强制覆盖。

标题作为快照元数据同步；接收已有对话默认保留本机标题，新对话默认采用快照标题，预览可修改。快照按设备独立保留。新对话需勾选纳入；取消勾选不会删除远端数据。离开前发布，到另一台先接收再继续。

应用不复制代码、资源或 Git 仓库。接收前请用现有工具准备目录和文件。接收后的验证分别检查内容、工作目录和原生项目归属，未完成可重试。

只修改本机原生项目归属，不移动代码或改写消息。原项目的同步成员会移除此对话；已发布快照不变。

通过 Codex 原生接口修改本机元数据。身份 ID、消息历史、工作目录不变。同步名称在项目属性中单独设置。
