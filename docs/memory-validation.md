# 0.15.3 内存验证

日期：2026-10-19。以下为本机合成数据测试结果，不包含用户会话或凭据。

| 样本大小 | 外部监控的进程工作集峰值 |
|---|---:|
| 8 MB | 117 MB |
| 32 MB | 237 MB |
| 138 MB | 260 MB |

每级单独运行，192 MB JavaScript 堆上限、384 MB 工作集停止阈值、3 分钟超时、低优先级。138 MB 流程约 15 秒，覆盖文件扫描、发布、校验下载、追加比较、备份恢复、冲突分叉与模拟 WebDAV 文件流。这里的 WebDAV 为流式模拟服务；未用真实账号传输合成大文件。没有在 Codex 原生后端中载入 138 MB 对话。

70 项小样本回归测试串行通过。打包在测试完全结束后执行。初次默认差分压缩被 768 MB 构建进程树阈值停止；改用低压缩等级 ZIP 且禁用差分包后，构建峰值约 410 MB。打包后的界面验证了项目展开／收起和草稿保留。

会话原文以文件流处理，预览有界。单文件上限 256 MB、单条 JSONL 记录上限 8 MB。过大的单条记录不自动截断或跳过，保留原文件并停止。Codex 原生验证优先只读元数据；超大的接口响应将停止验证并保留恢复报告。上述测量不包括用户日常运行的 Codex 或其他应用。

## 0.15.4：内嵌大图片记录

内嵌 `data:image/...;base64,` JSON 字符串改为摘要和源文件字节区间处理。扫描、比较不会将图片整体转为字符串或交给 JSON.parse；路径映射和分叉按区间流式复制原始图片。图片字符串仍验证转义与控制字符；截断或损坏的记录会停止恢复。非图片内容保留每条 8 MB 上限，整个文件仍为 256 MB。

2026-10-19 合成测试：单条 32 MB 图片记录完整流程峰值 90 MB；单条 138 MB 图片记录完整流程峰值 92 MB，约 20 秒。普通 32 MB 多记录文本回归峰值 240 MB。沿用 192 MB 堆上限、384 MB 工作集停止阈值和 3 分钟超时，所有测试串行运行。测试涵盖发布、模拟 WebDAV 传输、图片字节校验、路径映射、相同／追加／冲突比较、备份和分叉；没有修改真实对话，也没有上传合成图片到真实云端。

72 项完整回归通过后，新增默认执行的超过 8 MB 图片回归测试也通过（合计 73 项）。专项测试还覆盖跨块字符、多个图片、JSON 属性顺序、损坏图片转义和未闭合字符串。测试结束后才单独打包。

安装包验证：首次连续 ZIP／NSIS 构建触发 768 MB 进程树保护并停止。修正为独立进程生成 ZIP，退出后再构建 NSIS，避免 .NET 压缩堆叠加。单独 NSIS 构建峰值 410 MB；打包后的应用通过隔离配置启动、版本、图标和项目收起／展开检查。
